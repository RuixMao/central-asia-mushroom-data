# 中亚食用菌市场周报生成模板 v4.1

必须同时执行 `common_v4_1.md`。

使命：判断本周趋势是否成形，以及下周应采用什么采购和出货节奏。面向老板和采购负责人，适合公众号阅读，篇幅约2至3屏。

标题：`中亚食用菌市场周报｜M月D日-M月D日：核心判断`

严格结构：

1. `## 上周判断回顾`：说明上一周重点判断是否兑现，给出本周数字或事实。
2. `## 本周速览`：不超过5条；每条为结论、依据、对下周的含义。
3. `## 价格走势`：按品类和形态列周首、周中、周末或周均价。只有同品类、同形态、同规格连续覆盖至少5个交易日，才可写趋势和周环比。
4. `## 本周事件回顾`：政策、海关、物流、认证事件及影响时间窗口；无事件写“本周无新增政策与事件，市场面平稳”。
5. `## 采购与成本提示`：汇率、运费、通关时效及其对货到口岸全部成本的影响。
6. `## 下周关注日历`：只写未来7天已有明确日期和来源的事件；没有则省略本节。
7. `## 行动建议`：固定为决策参考、采购落地、报价规范。
8. `## 数据说明`：只出现一次。

自检：速览不超过5条；趋势满足5个交易日门槛；关注日历无编造事件；开篇完成上周判断兑现回顾。
