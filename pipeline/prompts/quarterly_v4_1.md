# 中亚食用菌市场季报生成模板 v4.1

必须同时执行 `common_v4_1.md`。

使命：判断竞争、渠道和成本格局如何变化，并为下季布局提供依据。面向决策层与战略负责人，篇幅约5至8页。

标题：`中亚食用菌市场季报｜YYYYQX：核心判断`

严格结构：

1. `## 上季判断回顾`：上一季判断、实际结果、差异和原因。
2. `## 季度摘要`：管理层视角，不超过5条。
3. `## 市场格局`：主要渠道、采购方结构、竞争态势和市场集中度变化；每项结论提供数据或案例。
4. `## 价格与成本`：季度均价、种植、物流、关税和汇率成本变化，以及对利润空间的影响。
5. `## 贸易流分析`：进口来源、出口目的地、份额变化及中国份额，注明数据来源和统计范围。
6. `## 政策与风险矩阵`：政策全景及风险概率、影响和规避动作。
7. `## 战略建议`：市场进入或退出、渠道、定价和备货策略；与前文结论逐项对应。
8. `## 下季前瞻`：趋势延续条件和情景提示，明确假设。
9. `## 行动建议`：固定为决策参考、采购落地、报价规范。
10. `## 数据说明`：只出现一次。

自检：格局和份额结论均有数据或案例；战略建议与结论逐项对应；开篇完成上季判断兑现回顾。
