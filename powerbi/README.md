# 因恒科技中亚菌类价格情报 Power BI 看板

这是一套可直接在 Power BI Desktop 中组装的四页看板工程材料。默认采用“暗色金融终端”主题，画布统一为 1920×1080。

## 一、导入数据

1. 打开 Power BI Desktop，新建空白报表。
2. 在“获取数据 → 空白查询”中创建函数 `获取数据`，内容使用 `power-query/生产数据连接.pq`。
3. 依次创建六个引用查询：价格明细、每日汇总、采集运行、采集错误、商品、菌种。
4. 将日期列设为“日期”，时间戳列设为“日期/时间”；金额及比例列设为小数。
5. 新建日期表：

```dax
日期 = CALENDAR(MIN('价格明细'[observation_date]), MAX('价格明细'[observation_date]))
```

6. 建立关系：日期[日期] 1:* 价格明细[observation_date]；日期[日期] 1:* 每日汇总[date]；商品[id] 1:* 价格明细[product_id]；菌种[id] 1:* 商品[speciesId]；采集运行[id] 1:* 采集错误[runId]。
7. 导入 `themes/因恒暗色金融终端.json`，并录入 `model/度量值.dax` 中的度量值。

## 二、统一画布与筛选器

- 四页画布均设为 1920×1080，自定义尺寸；页面背景 `#0A0E14`。
- 页面边距 32px，8pt 网格；顶部页头 64px、KPI 带 150px、中部 500px、底部 280px。
- 全局同步切片器：国家中文全称、日期范围、菌种；默认全选。
- 所有数字启用等宽数字并右对齐。美元两位小数，比例一位小数。
- 使用绿色表示上涨、红色表示下跌；不使用渐变、阴影、3D 或装饰图标。

## 三、四页视觉对象清单

### 01 价格总览

- KPI：最新五国中位价、一日价格变化、缺货率、促销占比、有效SKU数。
- 中部矩阵：行=国家中文全称，列=菌种名称，值=五国中位价；背景色以蓝色深浅条件格式编码。
- 底部横向条形图：轴=国家中文全称，值=五国中位价；按数值降序，数据标签显示 `$0.00`。

### 02 价格趋势

- 主折线：轴=日期，值=五国中位价；图例=价格类型（中位价/促销价，可用字段参数）。
- 侧栏条形图：轴=国家中文全称，值=七日涨跌；绿色正值、红色负值。
- 底表：国家、城市、菌种、商品原名、规格公斤数、美元/公斤、一日涨跌；默认按日期倒序。

### 03 市场结构

- KPI：缺货率、促销占比，并显示相较前一日变化。
- 城市覆盖条形图：轴=城市，值=有效SKU数，工具提示加入缺货率。
- 散点图：X=有效SKU数，Y=缺货率，图例=国家中文全称，明细=城市。
- 底表：城市、菌种、有效SKU、缺货率、促销占比、数据质量等级。

### 04 采集运维

- KPI：采集成功率、采集失败数、平均运行时长秒。
- 最近14次运行时间轴：轴=startedAt，值=validRecords，数据色使用运行状态颜色。
- 错误原因条形图：轴=code，值=错误记录数，按降序显示前10项。
- 底表：开始时间、国家中文全称、平台、状态、发现SKU、有效记录、失败记录、运行时长。

## 四、验收

- 所有界面文案使用中文全称；KZ/UZ/KG/TJ/TM 只保留在模型层。
- 跨国价格统一使用 `normalized_usd_per_kg`，不要使用每包美元价比较不同规格。
- 仅统计 `validation_status=valid` 的记录（专用接口已完成过滤）。
- Power BI Desktop 中逐页检查交互：切片器、矩阵选择、图表联动、排序与工具提示。

## 五、限制

当前环境未安装 Power BI Desktop，因此这里没有伪造无法验证的 `.pbix` 文件。上述材料已覆盖数据连接、主题、关系、DAX 和四页构建说明；在安装了 Power BI Desktop 的 Windows 机器上按本说明导入即可生成 `.pbix`。
