# 中亚食用菌市场看板：口径与使用说明

## 看板用途

本看板面向进口商、渠道商和投资研究人员，用于比较中亚五国的食用菌零售挂牌价格、年度进口趋势与物流时效。它提供市场观察依据，不代表成交报价、采购承诺或投资建议。

## 指标口径

| 指标 | 来源与解释 |
|---|---|
| 五国均价（美元/公斤） | 有效零售观察先按包装净重折算成 USD/kg，再取中位数。属于线上或公开渠道挂牌价，不是成交价。 |
| 今日有效价格条数 | 最新观察日中 `validation_status=valid` 且可计算 USD/kg 的记录数。 |
| 覆盖国家数 | 当前筛选范围内存在有效零售记录的国家数，最多为 5。 |
| 进口单价 | UN Comtrade 的进口额除以净重，属于海关年度贸易口径，不等同于零售价格。 |
| 物流时效 | 数据源记录的路线中位天数；不是承运商的时效承诺。 |
| 有效记录占比 | 有效零售记录数除以全部零售记录数，反映记录质量，不等同于采集源有效率。 |
| 数据缺口率 | 今日有效来源数除以应采来源总数后取补数。只有具备来源计划分母时才能显示。 |

## 使用规则

1. 跨国比较只看“美元/公斤”，不要用当地币挂牌价或“每包美元价”直接比较。
2. 零售价格与贸易进口单价分属不同市场层级，不在同一坐标轴混用。
3. gap、缺失历史和无法换算的价格均显示为空白，不显示为 0。
4. 环比/同比需要可比历史；零售有效日期不足 3 天时返回空白。
5. 默认绿色代表上涨、红色代表下跌。

## 规格价差说明

300g 等小包装在折算为每公斤后，通常高于 1kg 大包装，这是包装、分拣、渠道和便利性溢价造成的正常现象。比较规格时应同时限定国家、品类、形态、渠道与相近观察日期。当前“300g”和“1kg”采用重量容差分组，规格未知记录不进入价差计算。

## 当前数据限制与需要补充的字段

交付检查时 `output/powerbi/` 尚未生成 CSV；首次搭建前需要运行既有导出流程。以下能力受现有 CSV 字段限制：

| 目标模块 | 当前缺口 | 建议补充字段及理由 |
|---|---|---|
| 精确 USD/kg | CSV 只有每包 `price_usd` | 当前可用 `price_usd / normalized_quantity_kg` 计算；长期建议直接导出 `normalized_usd_per_kg`，避免口径误用 |
| 跨日 SKU 跟踪 | 无稳定 SKU ID | 补充 `product_id`，否则同名商品可能误合并 |
| 源有效率/缺口率 | 无应采来源分母、无稳定来源键 | 补充 `source_id`、计划启用状态、计划采集日期 |
| 促销占比 | 无促销价或促销标记 | 补充 `promotion_price`、`is_promotion` |
| 缺货率 | 无库存状态 | 补充 `in_stock` |
| 研报联动 | 无报告地址 | 补充经审核的 `report_url`、报告日期、报告类型 |
| 可靠规格比较 | 仅有归一化重量，无原包装描述 | 补充 `package_value`、`package_unit` 或 `package_display` |
| 物流波动 | 只有中位天数 | 若需置信区间，补充样本量、P25、P75、最小/最大天数 |

这些字段应由后续数据产品版本补充；本次交付不修改 `pipeline/` 或 `local/` 采集与导出代码。

## 刷新建议

- 本地搭建阶段：每次导出 CSV 后，在 Power BI Desktop 手动刷新并核对行数和最新日期。
- 发布后：通过受支持的数据源或网关设置计划刷新。不同许可的刷新上限可能调整，应以当前 Power BI Service 租户页面为准。
- 刷新完成后检查“数据新鲜度”角标；超过 3 天应显示红色“过期”。
- 数据旧但仍可查看时，必须保留最后成功日期，不能标注为实时。

## 决策提示

“价格洼地”仅表示当前筛选条件下的相对低挂牌价。做采购或投资判断时，还需同时考虑税费、合规、汇率、损耗、冷链、物流时效、供货稳定性和商品规格差异。
