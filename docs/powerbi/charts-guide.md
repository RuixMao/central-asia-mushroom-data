# Power BI 图表搭建指南

## 1. 一次性准备

1. 运行既有导出流程，确认 `prices.csv`、`trade.csv`、`logistics.csv` 已生成。
2. Power BI Desktop → 获取数据 → 文本/CSV，逐一导入。
3. 在 Power Query 中按 `data-model.md` 重命名列、设置类型并新增“美元每公斤”“规格组”。
4. 如需缺口分析，通过 SQLite/ODBC 或单独查询导入 `data_snapshots` 的 gap 记录；没有可靠分母时不要显示“缺口率”。
5. 创建日期、国家、品类、形态、渠道和 HS 维度，建立单向一对多关系。
6. 新建“度量值”表，逐项录入 `dax-measures.md`。
7. 页面设为 1920×1080；背景 `#0A0E14`，卡片 `#131A24`，主字 `#E8ECF1`，次字 `#8A94A6`，强调蓝 `#3D7EFF`。
8. 全局同步切片器：国家、日期、品类、形态、渠道。

## 2. 总览驾驶舱

| 视觉对象 | 字段/度量 | 设置 |
|---|---|---|
| KPI 卡片 | 双孢菇均价、覆盖国家数、今日有效价格条数、数据缺口率、物流平均时效 | 缺口率不可计算时用“数据待补”，不要显示 0% |
| 矩阵热力图 | 行=国家中文全称；列=品类；值=五国均价 | 原生矩阵；背景条件格式使用单一蓝色色阶；单元格显示 `$0.00` |
| 国家价格条形图 | 轴=国家中文全称；值=五国均价 | 横向、升序；最低价强调蓝，其余灰蓝 |
| 新鲜度角标 | 数据新鲜度状态、最新数据距今天数 | 卡片背景按“数据新鲜度颜色”条件格式 |

布局：顶部 5 张等宽 KPI；中部左侧 2/3 为热力图，右侧 1/3 为国家排行；底部放口径说明和刷新时间。

## 3. 价格分析

| 视觉对象 | 字段/度量 | 设置 |
|---|---|---|
| 五国价格对比 | 轴=国家；值=五国均价；小倍数=品类 | 原生簇状条形图 |
| 品类价格带 | 轴=品类；值=最小/中位/最大美元每公斤 | 原生折线+柱形组合，或误差线 |
| 箱线图 | 类别=国家或品类；值=美元每公斤 | 使用经过组织批准的箱线图自定义视觉；若不允许，自建分位数表替代 |
| 形态价差卡片 | 鲜品中位价、腌渍中位价、形态价差 | 同时展示两个基准，避免只报差值 |
| 规格价差卡片 | 300g中位价、1kg中位价、规格价差 | 明确均已折算成 USD/kg |
| SKU 明细表 | 国家、城市、品类、商品原名、形态、规格组、渠道、美元每公斤、日期 | 数字右对齐；日期倒序；开启钻取页 |

交互：选择国家条形图后，其余图表交叉筛选；在“编辑交互”中避免 KPI 反向过滤切片器。

## 4. 贸易趋势

- 折线图：X=年度，Y=加权进口单价，图例=国家中文全称，小倍数或切片器=HS。
- 进口额柱形图：X=年度，Y=年度进口额，图例=国家。
- 同比条形图：轴=国家，值=进口额同比或进口单价同比，正值绿、负值红。
- 工具提示：年度、国家、HS、进口额、进口量、加权单价、同比。

年度范围默认 2018–2025；若 CSV 缺少某年，不补 0，折线应断开或显示空白。

## 5. 物流时效

- 横向条形图：Y=路线，X=线路中位时效，图例=国家。
- KPI：最快线路、最慢线路、线路时效差。
- 明细表：国家、路线、中位天数、观察时间。
- 同一线路有多次观察时，默认使用最新观察；若要看历史，加入日期切片器。

## 6. 数据质量监控

- 卡片：有效记录占比、缺口记录数、异常价格数、最新数据距今天数。
- 环形图：图例=validation_status，值=记录数；仅质量页允许显示全部状态。
- gap 原因条形图：轴=reason，值=缺口记录数。
- 采集趋势：X=日期，Y=有效记录占比或有效记录数。

“源有效率”和“数据缺口率”只有在导入计划来源分母后才能启用。没有分母时，页面标题旁显示“当前展示缺口记录，不等同于缺口率”。

## 7. 决策支持

- 价格洼地排行：表格放国家、五国均价、国家价格排名、价格洼地。
- 价格高地排行：同表增加价格高地排名。
- 情景参数：建模 → 新建参数 → 数值范围 -0.30 到 0.30，步长 0.01；用“情景采购成本”展示价格变化后的结果。
- 研报入口：仅在数据中补入有效 `report_url` 后添加 Web URL 条件格式按钮。当前 CSV 无此字段，不要写死虚构链接。

## 8. 新鲜度角标

1. 新建“最新数据距今天数”“数据新鲜度状态”“数据新鲜度颜色”度量。
2. 插入卡片，值使用“数据新鲜度状态”。
3. 背景 → fx → 格式样式选择“字段值” → 选择“数据新鲜度颜色”。
4. 工具提示加入“最新数据距今天数”和“今日日期”。

## 9. 发布与刷新

1. 文件 → 发布 → 选择工作区。
2. 在 Power BI Service 中配置数据源凭据或本地数据网关。
3. 执行一次手动刷新并核对三张事实表行数。
4. 检查五国均价抽样：必须等于 `price_usd / normalized_quantity_kg` 的中位数，而不是每包美元价。
5. 设置计划刷新；免费/Pro/Premium 的实际次数以当前租户许可页面为准。
6. 刷新失败时保留上次成功数据，并在页面显示新鲜度，不把旧数据标成“实时”。
