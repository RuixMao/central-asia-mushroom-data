# 平台四项清单核查与补齐记录

日期：2026-08-24

## 结论

四项清单已达到可交付状态：平台已有清晰能力清单；哈萨克斯坦、乌兹别克斯坦已有市场容量、竞争来源、风险和验证条件；哈萨克斯坦已补入 3 条公开物流参考价；五国均已用线上页面取得可进入正式价格表的商品记录。2026-08-24 已完成五国正式任务、生产写入及客户价格页读取验证。尚未完成的是“食用菌冷链的定向询价”和“所有候选来源稳定可用”，原因与后续动作见文末。

## 2. 两个重点国家

### 哈萨克斯坦

- 市场容量：2024 年已确认 HS 070951 与 200310 进口金额合计 600.1 万美元；其中鲜/冷双孢蘑菇 464.7 万美元。
- 竞争来源：进口国申报为主，可按伙伴国拆分；平台当前同时展示中国出口镜像。中国金额占比必须按具体 HS 分别使用，避免把不同形态混为一体。
- 价格和渠道：阿拉木图已覆盖电商、商超、小批发和批发观察。
- 主要风险：公开挂牌价不等于批发成交价；3 条物流价格均为普货基准，不包含食用菌温控与损耗责任。
- 需要验证：同规格批发成交、冷链温区、口岸查验、标签与进口主体要求。

### 乌兹别克斯坦

- 市场容量：2024 年已确认 HS 070951 与 200310 进口金额合计 52.8 万美元；鲜/冷双孢蘑菇 45.7 万美元。
- 竞争来源：进口国申报可确认规模，鲜品来源国结构和中国份额需要继续按伙伴国明细补强。
- 价格和渠道：2026-08-24 Yukber 线上实测取得双孢菇、平菇各 1 条正式价格记录。
- 主要风险：零售规格与批发规格不可直接比较；塔什干渠道成交价、账期和稳定供货关系尚未形成连续记录。
- 需要验证：批发成交、净重、产地、准入、喀什—塔什干冷链报价和损耗。

## 未完成项、原因与继续动作

1. 食用菌冷链真实询价尚未取得。公开网页只提供普货条件，货代无法在缺少温区、重量、体积、起运地、目的仓和贸易条款时给出可执行冷链报价。下一步以“1 吨鲜双孢菇、0–4℃、喀什—阿拉木图、门到仓”为统一询价单，向至少 3 家具备食品冷链资质的货代取同口径报价。
2. UZ、TJ、TM 仍需第二稳定来源。原因是当地公开电商覆盖少、部分页面缺价或接口不稳定。继续保留固定商品页，并按周复测第二来源。
3. Wildberries 不适合继续放在日常主链路。2026-08-24 实测出现 429、403、498，并把单国任务拖长数分钟；现已调整为低频显式复测，避免影响五国日常采集。
4. 物流模块仍只自动采集时效。后续需要新增“报价条件、币种、计价单位、有效期、是否含清关、是否冷链”字段，只有同口径报价才能形成趋势。
